# Drop Elias photos here

Put any number of `.jpg`, `.jpeg`, `.png` or `.webp` files in this folder and
they are used everywhere on the site automatically (hero, heads, gallery,
multiverse, photo wall, confetti…). No code changes needed.

Tips:
- More photos = more chaos. 10+ is ideal, 20+ is perfect.
- Transparent PNG cutouts work great: name them with `cutout` in the file name
  (e.g. `elias-cutout-1.png`) and they will be used for the floating stickers
  and the history cards.
- Files are used in alphabetical order. The first file is the giant hero image.
